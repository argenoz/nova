Классы Halfmoon для рамок и стилизации

Название класса Описание
border Добавляет рамку со всех сторон
rounded Закругляет углы элемента
shadow Добавляет тень под элементом
p-1 Маленький отступ внутри (padding)
p-2 Средний отступ внутри
p-3 Большой отступ внутри
m-1 Маленький отступ снаружи (margin)
m-2 Средний отступ снаружи
m-3 Большой отступ снаружи
card Создаёт красивую карточку с рамкой и тенью
card-body Контейнер для содержимого карточки
card-title Стилизованный заголовок карточки
d-flex Включает режим Flexbox
d-none Скрывает элемент
text-center Выравнивает текст по центру
btn Базовый стиль для кнопки
btn-primary Основная кнопка (синяя)
btn-danger Опасная кнопка (красная)
form-control Стилизует input, textarea, select
form-group Группирует элементы формы
