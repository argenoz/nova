Полный справочник классов Halfmoon

Отступы внутри (Padding)

Класс Описание
p-0 Отступ 0 со всех сторон
p-1 Маленький отступ со всех сторон
p-2 Средний отступ со всех сторон
p-3 Большой отступ со всех сторон
pt-1, pt-2, pt-3 Отступ сверху (padding-top)
pb-1, pb-2, pb-3 Отступ снизу (padding-bottom)
pl-1, pl-2, pl-3 Отступ слева (padding-left)
pr-1, pr-2, pr-3 Отступ справа (padding-right)
px-1, px-2, px-3 Отступ слева и справа (padding-left и padding-right)
py-1, py-2, py-3 Отступ сверху и снизу (padding-top и padding-bottom)

Отступы снаружи (Margin)

Класс Описание
m-0 Отступ 0 со всех сторон
m-1 Маленький отступ со всех сторон
m-2 Средний отступ со всех сторон
m-3 Большой отступ со всех сторон
mt-1, mt-2, mt-3 Отступ сверху (margin-top)
mb-1, mb-2, mb-3 Отступ снизу (margin-bottom)
ml-1, ml-2, ml-3 Отступ слева (margin-left)
mr-1, mr-2, mr-3 Отступ справа (margin-right)
mx-1, mx-2, mx-3 Отступ слева и справа (margin-left и margin-right)
my-1, my-2, my-3 Отступ сверху и снизу (margin-top и margin-bottom)
mx-auto Центрирует элемент горизонтально

Рамки и закругления

Класс Описание
border Добавляет рамку со всех сторон
border-top Рамка только сверху
border-bottom Рамка только снизу
border-left Рамка только слева
border-right Рамка только справа
rounded Закругляет все углы
rounded-top Закругляет верхние углы
rounded-bottom Закругляет нижние углы
rounded-left Закругляет левые углы
rounded-right Закругляет правые углы
shadow Добавляет тень под элементом

Дисплей и видимость

Класс Описание
d-none Скрывает элемент (display: none)
d-block Блочный элемент (display: block)
d-inline Встроенный элемент (display: inline)
d-inline-block Встроенный блочный элемент (display: inline-block)
d-flex Flexbox контейнер (display: flex)
d-grid CSS Grid контейнер (display: grid)
d-md-none Скрывает на средних экранах и больше
d-md-block Показывает как блок на средних экранах и больше
invisible Скрывает элемент, но оставляет место

Flexbox утилиты

Класс Описание
justify-content-start Выравнивает элементы в начало
justify-content-center Выравнивает элементы по центру
justify-content-end Выравнивает элементы в конец
justify-content-between Распределяет элементы с равными промежутками
justify-content-around Распределяет элементы с отступами вокруг
align-items-start Выравнивает элементы в начало по вертикали
align-items-center Выравнивает элементы по центру по вертикали
align-items-end Выравнивает элементы в конец по вертикали
flex-row Элементы в ряд (по горизонтали)
flex-column Элементы в колонку (по вертикали)
flex-wrap Элементы переносятся на новую строку
flex-nowrap Элементы не переносятся

Размеры

Класс Описание
w-100 Ширина 100%
w-auto Ширина авто
h-100 Высота 100%
h-auto Высота авто
mw-100 Максимальная ширина 100%
mh-100 Максимальная высота 100%

Текст и выравнивание

Класс Описание
text-left Выравнивает текст влево
text-center Выравнивает текст по центру
text-right Выравнивает текст вправо
text-justify Выравнивает текст по ширине
text-primary Текст основного цвета (синий)
text-secondary Текст вторичного цвета (серый)
text-success Текст зелёного цвета (успех)
text-danger Текст красного цвета (опасность)
text-warning Текст оранжевого цвета (предупреждение)
text-info Текст голубого цвета (информация)
text-muted Текст приглушённого цвета
text-white Белый текст
font-weight-light Лёгкий вес шрифта
font-weight-normal Обычный вес шрифта
font-weight-bold Жирный шрифт
text-decoration-none Убирает подчеркивание
